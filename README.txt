BRIMSTONE — minimal image-only website

Deploy on Vercel:
1. Extract this folder.
2. Open https://vercel.com/new and import a Git repository containing these files,
   OR install the Vercel CLI and run `vercel` from this folder.
3. Keep the project as a static site. No build command or framework preset is needed.
4. Deploy.

The page displays only the supplied artwork, centered and scaled to fit the screen.
